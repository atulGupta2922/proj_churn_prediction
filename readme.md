# Project: Churn Prediction

### Setup
Run the following commands from the home directory of this project:
```shell
# Download the dataset file (.zip)
curl -L -o ./data/raw/online-retail-ii-uci.zip\
  https://www.kaggle.com/api/v1/datasets/download/mashlyn/online-retail-ii-uci
```
```shell
# Extract the zip
unzip data/raw/online-retail-ii-uci.zip -d data/raw/
```
